# Comandos oficiais

- `npm run dev`: inicia o servidor `stdio` e abre o painel local de orientação em `127.0.0.1`.
- `npm run build`: compila para `dist`.
- `npm start`: executa a compilação.
- `npm run typecheck`: valida os tipos sem emitir arquivos.
- `npm run lint`: executa ESLint.
- `npm test`: executa a suíte padrão sem serviços reais.
- `npm run test:coverage`: executa a suíte com cobertura.
- `npm run test:live`: smoke test somente leitura, opt-in por `MCP_LIVE_TESTS=CONFIRMO_LEITURA`.
- `npm run inspector`: abre o MCP Inspector.
- `npm run validate:workflow`: valida `.specs`, skills, links essenciais e sinais comuns de segredo.
