Como usar, passo a passo

O caminho recomendado para quem está começando.

Deixe as credenciais no .env

As credenciais de cada integração ficam somente neste computador. Não compartilhe esse arquivo.

Use npm run dev para orientação

Este painel abre e o processo fica ativo até você pressionar Ctrl+C. Ele não conecta sozinho uma IA.

Compile com npm run build

Isso cria a versão estável em dist/index.js, usada pelo Codex ou outro cliente MCP.

Configure o cliente MCP

Copie o exemplo de .codex/config.toml.example para a configuração do Codex e reinicie o aplicativo.

Comece por consultas

Peça para listar work items, consultar áreas, procurar páginas ou localizar mídias antes de testar alterações.

Confirme cada escrita

A IA prepara e mostra o diff. Só diga CONFIRMO depois de revisar o alvo e as mudanças.
